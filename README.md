🏠 Rent Distribution Calculator (Python Tkinter)
📌 Project Description

The Rent Distribution Calculator is a GUI-based Python application built using Tkinter.
It helps users easily calculate how much rent each person has to pay by dividing the total monthly rent and utilities cost among a given number of people.

This project is useful for roommates, students, or shared apartments.

🎯 Objectives

To calculate fair rent distribution

To practice GUI development using Tkinter

To understand basic calculations and error handling in Python

To build a clean and user-friendly desktop application

🛠 Technologies Used

Python 3

Tkinter

ttk (Themed Tkinter widgets)

📂 Features

✔ Simple and clean GUI
✔ Input total rent, utilities, and number of people
✔ Automatically calculates total cost
✔ Displays rent per person
✔ Uses Indian Rupee (₹) symbol
✔ Error handling for invalid inputs

🖥 How the Application Works

User enters:

Total Monthly Rent

Utilities Cost

Number of People

Clicks Distribute Rent

Application calculates:

Total cost (rent + utilities)

Rent per person

Result is displayed on the screen# Rent-calculator
